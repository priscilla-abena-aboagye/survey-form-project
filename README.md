# Survey Form Project

A simple and responsive **Survey Form** created using HTML and CSS. This project gathers feedback from users to evaluate the impact of a given activity or service.

-----

## Overview

The Survey Form is a beginner-friendly project designed to help collect user feedback. It includes various input fields such as text, email, number, dropdown, checkboxes, radio buttons, and a textarea for comments.

-----

## Technologies Used

- HTML5: For the structure of the website.
- CSS: For styling and layout of the website.
